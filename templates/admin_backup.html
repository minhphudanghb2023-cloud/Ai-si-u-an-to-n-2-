💾 Backup ngay

Tạo backup thủ công ngay lập tức. Dữ liệu sẽ được lưu vào OneDrive (không bao giờ mất) và Local (truy cập nhanh).

📤 Export dữ liệu

Tải toàn bộ dữ liệu (users, nhật ký, báo cáo) về máy tính dạng file JSON. Dùng để:

  • Archive vĩnh viễn
  • Chuyển sang máy khác
  • Phân tích dữ liệu

📥 Import dữ liệu

Khôi phục dữ liệu từ file JSON đã export trước đó. Cảnh báo: Dữ liệu cũ sẽ được backup trước khi import.
